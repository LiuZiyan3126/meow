# MEOW 项目部署与训练指南

## 一、项目文件清单

确保以下文件完整，打包上传到云服务器：

```
meow.py                          # 入口（已集成 LightGBM + ResidualMLP 集成推理）
src/
  __init__.py
  log.py                         # 日志
  tradingcalendar.py             # 交易日历
  dl.py                          # 数据加载器
  feat.py                        # 特征工程（62 特征）
  nn_model.py                    # ResidualMLP 网络结构
  mdl.py                         # ResidualMLP 训练/推理
  mdl_lgb.py                     # LightGBM 训练/推理（新增）
  eval.py                        # 评估器
archive/                         # HDF5 数据文件（20230601.h5 ~ 20231229.h5）
scripts/                         # 辅助脚本（不需要可忽略）
doc/                             # 文档（不需要可忽略）
```

## 二、本地准备工作

### 2.1 安装 LightGBM

```powershell
pip install lightgbm
```

### 2.2 打包项目（不含缓存和模型文件）

```powershell
# 在项目根目录执行
# 打包时不包含 __pycache__、模型权重文件、doc 目录
# 使用 7-Zip 或 tar 打包
tar -cvf meow_project.tar --exclude="__pycache__" --exclude="*.pt" --exclude="*.pkl" --exclude="*.txt" --exclude="doc" --exclude=".git" meow.py src/ archive/
```

> **注意**：`archive/` 目录包含约 130 个 `.h5` 文件（每个交易日一个），总大小约 5-10 GB，确保云服务器有足够磁盘空间。

## 三、云服务器部署

### 3.1 推荐平台

| 平台 | 特点 | 网址 |
|------|------|------|
| AutoDL | 国内首选，按量计费，预装 PyTorch | autodl.com |
| 矩池云 | 国内，学生优惠 | matpool.com |
| Vast.ai | 海外，价格低 | vast.ai |
| Google Colab | 免费，但限时 | colab.research.google.com |

> 本项目 LightGBM 训练仅需 **CPU**，ResidualMLP 训练需要 **GPU**。如果两个模型都要在云上训练，选择带 GPU 的实例。

### 3.2 环境配置

SSH 登录云服务器后执行：

```bash
# 1. 确认 Python 版本 >= 3.8
python --version

# 2. 安装依赖
pip install torch scikit-learn pandas numpy tables lightgbm

# 3. 验证安装
python -c "import lightgbm; print('LightGBM', lightgbm.__version__)"
python -c "import torch; print('PyTorch', torch.__version__); print('CUDA', torch.cuda.is_available())"
```

### 3.3 上传项目

```bash
# 在云服务器上创建项目目录
mkdir -p ~/meow

# 从本地上传（在本地 PowerShell 执行）
scp meow_project.tar root@<服务器IP>:~/meow/

# 在云服务器上解压
cd ~/meow
tar -xvf meow_project.tar

# 确认文件结构
ls -la
ls archive/ | head -5   # 应该看到 20230601.h5 等文件
```

## 四、训练流程

### 4.1 方案一：分步训练（推荐）

ResidualMLP 用 GPU 训练，LightGBM 用 CPU 训练，可以分开执行：

**第一步：训练 ResidualMLP（需要 GPU）**

```bash
python -c "
from src.log import log
from src.dl import MeowDataLoader
from src.feat import MeowFeatureGenerator
from src.mdl import MeowModel
from src.tradingcalendar import Calendar

calendar = Calendar()
dloader = MeowDataLoader(h5dir='./archive')
featGen = MeowFeatureGenerator(cacheDir=None)

dates = calendar.range(20230601, 20231130)
rawData = dloader.loadDates(dates)
xdf, ydf = featGen.genFeatures(rawData)

model = MeowModel(cacheDir=None)
model.fit(xdf, ydf)
log.inf('ResidualMLP training done.')
"
```

训练完成后得到 `model_weights.pt` 和 `scaler.pkl`。

**第二步：训练 LightGBM（CPU 即可）**

```bash
python -c "
from src.log import log
from src.dl import MeowDataLoader
from src.feat import MeowFeatureGenerator
from src.mdl_lgb import MeowModelLGB
from src.tradingcalendar import Calendar

calendar = Calendar()
dloader = MeowDataLoader(h5dir='./archive')
featGen = MeowFeatureGenerator(cacheDir=None)

dates = calendar.range(20230601, 20231130)
rawData = dloader.loadDates(dates)
xdf, ydf = featGen.genFeatures(rawData)

model = MeowModelLGB(cacheDir=None)
model.fit(xdf, ydf)
log.inf('LightGBM training done.')
"
```

训练完成后得到 `lgb_model.txt` 和 `lgb_scaler.pkl`。

### 4.2 方案二：一键训练

如果服务器同时有 GPU（训 ResidualMLP）+ CPU 核（训 LightGBM），可以直接运行：

```bash
python meow.py
```

首次运行时两个模型文件都不存在，会自动依次训练 ResidualMLP 和 LightGBM，然后评估集成效果。

### 4.3 预期训练时间

| 模型 | 硬件 | 预计时间 |
|------|------|----------|
| ResidualMLP | GPU (RTX 4060) | 15-30 分钟 |
| ResidualMLP | CPU (16 核) | 2-3 小时（不推荐） |
| LightGBM | CPU (8 核) | 5-10 分钟 |

## 八、常见问题

### Q1: `ModuleNotFoundError: No module named 'lightgbm'`

```bash
pip install lightgbm
```

### Q2: 云服务器内存不足（OOM）

LightGBM 训练需要将 6 个月约 700 万行数据加载到内存，约需要 8-16 GB RAM。如果内存不够：
- 选择更高配的云实例（16 GB+ RAM）
- 或减小训练集日期范围

### Q3: 只训了 LightGBM、ResidualMLP 没训怎么办

不需要重新训 ResidualMLP。把已有同学的 `model_weights.pt` 和 `scaler.pkl` 直接复制到项目根目录即可。`meow.py` 会自动检测并跳过训练。

### Q4: 如何只训 LightGBM（不训 MLP）

把训练好的 `model_weights.pt` + `scaler.pkl` 放到项目根目录，然后运行：

```bash
python -c "
from src.log import log
from src.dl import MeowDataLoader
from src.feat import MeowFeatureGenerator
from src.mdl_lgb import MeowModelLGB
from src.tradingcalendar import Calendar

calendar = Calendar()
dloader = MeowDataLoader(h5dir='./archive')
featGen = MeowFeatureGenerator(cacheDir=None)
dates = calendar.range(20230601, 20231130)
rawData = dloader.loadDates(dates)
xdf, ydf = featGen.genFeatures(rawData)
lgb = MeowModelLGB()
lgb.fit(xdf, ydf)
"
```

这样只生成 `lgb_model.txt` + `lgb_scaler.pkl`，MLP 的权重文件不受影响。

### Q5: 服务器没有 GPU 能训吗

- **LightGBM**：纯 CPU，完全没问题
- **ResidualMLP**：可以在 CPU 上训练但很慢（2-3 小时）。或者只从同学的 GPU 机器上拿 `model_weights.pt` + `scaler.pkl` 拷贝过来。

### Q6: 如何只做推理、跳过所有训练

确保 4 个模型文件都在项目根目录，然后运行 `python meow.py`。代码会自动检测文件存在并跳过训练，直接进入评估。
