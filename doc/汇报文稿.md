## 零、项目概述（30 秒开场）

**我们做了什么？**

利用约 300 只 A 股 7 个月的分钟级高频订单簿数据，预测 12 分钟后的中间价变化率 `fret12`。

**核心成果：**
- Pearson 相关系数从基线 **0.025 → 0.0643**（2.6 倍提升）
- 达到课程预期 5-10% 区间
- 构建 7 大类 62 特征体系 + ResidualMLP 神经网络
- 使用 AI（Claude Code）全流程辅助开发，探索大模型在 P-quant 因子挖掘中的创新应用

| 环节 | 传统做法 | 我们的 AI 辅助做法 |

| 效率优化 | StackOverflow 搜索 → 试错 | AI 直接指出 Cython 级 `groupby().rolling()` 原生路径，一次性规避 lambda 性能陷阱 |
| 模型搭建 | 查 PyTorch 文档 → 手写训练循环 | AI 生成样板代码（训练循环、早停、checkpoint），我们聚焦架构决策 |
| 超参搜索 | 手动改参数 → 跑实验 → 记录 | AI 生成批量实验脚本 + 自动解析日志，10+ 组实验一夜跑完 |

### 1.2 创新点：大模型辅助因子挖掘的范式探索

我们总结出一套 **"AI 提议 → 人工审核 → 实验验证"** 的三阶段因子挖掘范式：

```
AI 提议候选因子（基于市场微观结构文献知识）
    ↓
人工审核：该因子是否有金融经济学逻辑？（过滤掉纯统计 artifacts）
    ↓
实验验证：消融实验量化边际贡献（7 类特征逐一移除对比）
    ↓
保留通过审核 + 正向贡献的因子
```

**具体案例**：
- AI 提议使用金额加权不平衡（ob_tr_imb）补充数量加权不平衡 → 人工判断：区分"大单（金额敏感）"与"散户（数量敏感）"，逻辑成立 → 通过
- AI 提议 trade_imb × spread_bps0 交互项 → 人工判断：宽价差时成交方向信号更可信（流动性差时主动成交更可能是知情交易），逻辑成立 → 通过
- AI 提议部分高阶多项式组合 → 人工判断：缺乏经济学解释，且易过拟合 → 否决

**启示**：大模型在因子挖掘中的价值不在于"自动发现"，而在于**加速"假设生成 → 验证"的迭代循环**。模型提供广度（覆盖更多候选），人类提供深度（经济学逻辑审核），实验提供客观筛选。

## 二、特征挖掘与特征工程（评分维度二）

### 2.1 数据分析（EDA）发现

对原始 62 列数据进行系统分析后，关键发现：

| 发现 | 数据 | 工程决策 |
|------|------|---------|
| Add/Cxl 类字段 ~2% 缺失 | 部分分钟无新增/撤单事件 | `fillna(0)` — 无活动即零值 |
| fret12 均值 ~0.0006，std ~0.007 | 目标值量级极小 | 标签缩放（训练 ×100，推理 ÷100） |
| 价差/成交量/收益率的量级跨越 4-5 个数量级 | 特征尺度差异极大 | BatchNorm + StandardScaler |
| 时序自相关性显著 | 金融数据天然特征 | 时序切分验证集（不用随机切分） |

### 2.2 特征体系总览：7 大类 62 特征

```
                     ┌──────────────────────────────┐
                     │     G. 交互特征 (4)           │
                     │   imb×spread, obi×ret ...    │
                     ├──────────────────────────────┤
                     │   F. 截面特征 (5)             │
                     │   去均值, 动量/反转             │
                     ├──────────────────────────────┤
                     │   E. 滚动时序统计 (16)         │
                     │   MA(5/12), STD(12/24) ...   │
                     ├───────────────┬──────────────┤
                     │ C. 成交流(10) │ D. 委托/撤单(10)│
                     │ 主动成交方向    │ 被动挂单意图    │
                     ├───────────────┴──────────────┤
                     │ A. 订单簿不平衡(8)│B. 价差微观(8)│
                     │ 数量/金额加权     │ spread/micro │
                     └──────────────────────────────┘
                          市场微观结构理论基础
```

### 2.3 各类特征设计逻辑

**A. 订单簿不平衡（8 特征）** — 核心问题：有多少股/多少钱在买 vs 卖？

| 创新设计 | 说明 |
|----------|------|
| 多档位分层（0/0_4/5_9/10_19） | 区分"浅层博弈"与"深层布局"——散户看买一卖一，机构看全档深度 |
| 数量 + 金额双维度 | ob_imb 衡量"股数不对称"，ob_tr_imb 衡量"资金不对称"。大单在金额维度暴露更明显 |

**B. 价差与微观结构（8 特征）** — 核心问题：现在交易成本多高？价格是否偏离均衡？

| 创新设计 | 说明 |
|----------|------|
| spread_slope（价差斜率） | 反映深度订单簿的陡峭程度，斜率越大流动性越集中 |
| micro_price（Kyle 1985） | 用最优档量加权的均衡价格，mp_dev 衡量中间价偏离 |

**C. 成交流（10 特征）** — 核心问题：主动成交的人在买还是卖？

| 创新设计 | 说明 |
|----------|------|
| 三维不平衡（量/笔数/金额） | 分别捕捉"有多少股""有多少人""有多少钱"在主动买卖。大单（金额）vs 散户（笔数）信号不同 |
| trade_intensity（活跃度） | 高活跃度时段的成交信号更可靠 |

**D. 委托/撤单（10 特征）** — 核心问题：限价单挂单人在想什么？

| 创新设计 | 说明 |
|----------|------|
| net_flow（净挂单流） | 新增 − 撤单 = 净挂单意愿变化。买方 net_flow 为正 → 买盘堆积 → 价格支撑 |
| add_cxl_ratio | 新增/(新增+撤单)，衡量挂单持续性 |

**E. 滚动时序统计（16 特征）** — 核心问题：特征的近期趋势和波动怎么样？

| 创新设计 | 说明 |
|----------|------|
| 三尺度窗口（5/12/24 min） | 5min=短线反应，12min=匹配预测目标，24min=波动率基准 |
| vol_ratio（成交量异常） | 当前量 / 历史均值 → 异常放量往往是信息事件信号 |
| ret_ma_accel（动量加速） | 短期动量 − 长期动量 → 动量是在加速还是减速 |

**F. 截面特征（5 特征）** — 核心问题：是这只股票特殊，还是整个市场在动？

截面去均值分离 **市场共同信号**（大盘、板块）与 **个股异质信号**。

**G. 交互特征（4 特征）** — 核心问题：A 信号在 B 条件下是否更有效？

将条件依赖关系显式化为特征，例如 `trade_imb × spread_bps0`：宽价差时（流动性差），成交方向信号更可能是知情交易。

### 2.4 特征工程效率优化（关键工程贡献）

**问题**：700 万行数据，对每只股票每天做 rolling window 计算。

**常见错误做法**：
```python
# 错误：lambda 逐组调用 Python 解释器 → OOM / 极慢
df.groupby(["symbol","date"])["col"].transform(lambda x: x.rolling(5).mean())
```

**我们的方案**（Pandas Cython 原生路径）：
```python
# 正确：Cython 级操作，700 万行 ~30 秒
df.set_index(["symbol", "date"])["col"].groupby(level=[0,1]).rolling(window=5).mean()
```

详见 `src/feat.py: MeowFeatureGenerator._rolling_mean()` 和 `_rolling_std()`。

## 三、模型定义、选择与创新设计（评分维度三）

### 3.1 为什么不用线性模型？

基线 Ridge 回归 Pearson 仅 2-3%。**金融市场的价格形成机制高度非线性**——订单簿不平衡对价格的影响随市场条件（价差、波动率、成交量）而变化：

- 同样是买盘占优（ob_imb0 > 0），在**窄价差高流动性**时可能只是噪声，在**宽价差低流动性**时可能是知情交易信号
- 线性模型只能学习"买盘多 → 涨"的平均效应，无法捕捉条件依赖

### 3.2 ResidualMLP 架构

```
Input(62) ──→ Linear(128) ──→ BN ──→ GELU ──→ Drop(0.2)
    │
    ├──→ Block1: 128→256, GELU, Drop(0.3)
    │       │
    │       ├──→ Block2: 256→256, GELU, Drop(0.3)  [+ identity skip]
    │       │       │
    │       │       └──→ Block3: 256→128, GELU, Drop(0.3)  [+ projection skip]
    │       │               │
    │       │               └──→ Block4: 128→64, GELU, Drop(0.2)
    │       │                       │
    │       │                       └──→ Head: 64→1 (linear, no activation)
```

**总参数量：~165K**（在 700 万样本上非常轻量，不易过拟合）

### 3.3 各组件设计理由

| 设计选择 | 理由 | 参考来源 |
|----------|------|---------|
| **GELU** 替代 ReLU | 零点附近平滑，对金融小信号更敏感，无死神经元 | Hendrycks & Gimpel (2016) |
| **BatchNorm1d** | 金融特征尺度差异 4-5 个数量级，BN 逐层标准化 + 正则化 | Ioffe & Szegedy (2015) |
| **残差连接**（仅中间层） | 缓解深层网络梯度消失，学习恒等映射的扰动 | ResNet, He et al. (2016) |
| **递减 Dropout** (0.2→0.3→0.2) | 中间层交互最复杂最易过拟合，输出前降低保留精度 | Srivastava et al. (2014) |
| **线性头部**（无激活） | 回归任务需无界输出，分类才用 Softmax/Sigmoid | 回归任务通用实践 |
| **AdamW** | 解耦权重衰减与自适应学习率，比 Adam 更有效抗过拟合 | Loshchilov & Hutter (2019) |
| **ReduceLROnPlateau** | val_loss 不降时自动减半 lr，后期精细收敛 | PyTorch 标准调度器 |

### 3.4 三大训练策略创新

**创新一：标签缩放（Target Scaling）**

```
问题：fret12 ≈ 0.0006，MSE(pred, y) 梯度 ≈ 0 → 梯度消失
方案：训练时 loss = MSE(pred, y × 100)
      推理时 prediction = model(x) / 100
效果：梯度放大 100 倍，训练稳定收敛
```

**创新二：时序验证集切分**

```
错误做法：train_test_split(shuffle=True)
         → 未来信息泄露 → 过拟合 → 真实场景崩溃

正确做法：按时间排序，最后 15% 日期作为验证集
         → 杜绝 look-ahead bias → 验证指标可信
```

**创新三：分批推理 + 模型持久化**

```python
# 推理安全：150 万样本不 OOM
with torch.no_grad():
    for i in range(0, len(X), 8192):
        ...

# 一次训练，反复演示
if os.path.exists("model_weights.pt"):
    engine.model.load(...)  # 跳过训练
```

### 3.5 与其他方案的差异化

我们了解到部分团队可能采用以下方案，我们选择了不同的技术路线以保持**稀有性**：

| 常见方案 | 我们的方案 | 差异化 |
|----------|-----------|--------|
| LSTM / GRU 时序模型 | ResidualMLP（前馈 + 残差） | MLP 更轻量，残差结构带来深度优势，且 LSTM 在高噪声金融数据上易过拟合 |
| LightGBM / XGBoost | PyTorch 神经网络 | 树模型需大量特征工程，NN 可端到端学习非线性交互 |
| 简单 MLP（无残差） | ResidualMLP | 残差连接保证深层梯度流动 |
| 随机交叉验证 | 时序切分验证 | 金融数据必须时序切分 |
| 仅用数量特征 | 数量 + 金额 + 交互 | 多维覆盖捕捉更丰富信号 |

## 四、实验结果（1 分钟快速过）

### 4.1 核心指标

| 指标 | Ridge 基线 | ResidualMLP（本方案） | 提升 |
|------|-----------|----------------------|------|
| **Pearson** | 0.025 | **0.0643** | **2.6×** |
| R² | < 0 | 0.0041 | — |
| MSE | — | 5.5×10⁻⁵ | — |

Pearson 6.43% 达到课程 5-10% 区间要求。

### 4.2 消融实验

| 移除特征组 | Pearson 下降 | 结论 |
|-----------|-------------|------|
| A. 订单簿不平衡 | **-0.015** | 基础信号，单类贡献最大 |
| E. 滚动时序统计 | **-0.012** | 动态信息是关键增量 |
| C. 成交流 | -0.008 | 主动成交方向信号 |
| B. 价差微观结构 | -0.003 | 流动性环境上下文 |

**结论**：所有 7 类特征均有正向贡献；特征扩展（+4pp）贡献大于模型替换（+1.5pp），两者结合效果最佳。

### 4.3 关键经验

- 特征 vs 模型的权衡：**特征做得好的收益 > 模型做得好**（验证了课程 TIPS 的观点）
- 超参敏感性：**学习率最敏感**（1e-3 最优，2e-3 震荡，5e-4 太慢），Dropout/weight_decay 在合理范围内鲁棒
