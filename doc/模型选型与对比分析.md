# 模型选型与对比分析

## 一、为什么没选树模型

其实不是"排除了"，是"选了另一条路走通了就没回头"。

### 决策逻辑

项目初始代码给的是 Ridge（线性），所以我们很自然地沿着"怎么突破线性"这条线思考。两条路：

- 路线 A：换树模型（LightGBM / XGBoost）
- 路线 B：换神经网络（MLP + 残差）

我们选了 B，理由是：

1. **和课程鼓励方向一致。** 课程文档明确写了"推荐大家使用神经网络这一类非线性模型"。

2. **神经网络方案汇报时更好讲。** 评分维度里"模型定义与创新设计"要求说明为什么选这个模型、有什么有意义的尝试。ResidualMLP 的每个组件（GELU、BN、残差、Dropout 递减）都能讲出设计理由和参考文献，树模型能讲的空间小一些。

3. **技能栈匹配。** 刘子彦熟悉 PyTorch，直接上手写了 src/nn_model.py 和 mdl.py。

### 坦率讲

如果今天重新选，会两个都用——LightGBM 训一个，ResidualMLP 训一个，预测值取平均。这个集成方案大概率比单独任何一个都高 0.5-1pp。当时没这么做主要还是时间有限。

## 二、可用方案排名（按预期 Pearson）

| 排名 | 方案 | 预期 Pearson | 一句话 |
|------|------|-------------|--------|
| 1 | **LightGBM + ResidualMLP 集成** | 7-8% | 树模型和非线性模型各取所长，取均值 |
| 2 | LightGBM / XGBoost | 6.5-7.5% | 树模型在表格数据上天然强 |
| 3 | **ResidualMLP（当前方案）** | **6.43%** | 就是我们现在的位置 |
| 4 | TabNet | 6-7% | 带注意力的表格网络，可解释性好 |
| 5 | 普通 MLP（无残差） | 5.5-6.5% | 比残差版略低，收敛更慢 |
| 6 | LSTM / GRU | 4-6% | 波动大，容易过拟合 |
| 7 | Ridge（原始基线） | 2.5% | 线性模型上限低 |
| 8 | DCN / DeepFM | 3-5% | 为稀疏特征设计，这里水土不服 |

**关键结论**：前 3 名差距不大（都落在 6-8% 区间），说明模型不是瓶颈，特征才是。从 7-8% 再往上走，不靠换模型，靠加另类数据。

### 树模型

| 模型 | 特点 | 适合吗 |
|------|------|--------|
| LightGBM | 速度快、leaf-wise 生长 | ✅ 很适合，大概率也能到 5-7% |
| XGBoost | 老牌稳定、正则化好 | ✅ 很适合 |
| CatBoost | 对数值特征处理更优 | ✅ 适合 |

### 普通神经网络

| 模型 | 特点 | 适合吗 |
|------|------|--------|
| **ResidualMLP** | **就是我们用的** | **✅ 当前方案** |

## 四、集成学习：树模型 + 神经网络

### 原理

树模型和神经网络看数据的方式不同：

| | LightGBM | ResidualMLP |
|------|-----------|-------------|
| 学什么 | 硬阈值分割，找最优切分点 | 连续非线性变换，光滑拟合 |
| 对噪声 | 对异常值天然鲁棒 | 需要正则化对抗 |
| 误差模式 | 某些样本高估 | 某些样本低估 |

两者犯的错**不完全重叠**，一平均，很多错互相抵消了。

### 简单平均

```python
# 各自预测
pred_lgb = lgb_model.predict(xdf)      # LightGBM 输出
pred_mlp = mlp_model.predict(xdf)      # ResidualMLP 输出

# 取平均
pred_final = (pred_lgb + pred_mlp) / 2
```

### Stacking（更高级）

```
第1层：LightGBM + ResidualMLP + XGBoost（多个基模型各自预测）
第2层：Ridge（拿第1层的预测值作为输入，学"该更信谁"）
```

对于只有两个模型的场景，简单平均就够，加权还不如直接平均稳定。

### 我们为什么没做

训练在同学 RTX 4060 上一台机器跑的。LightGBM 在 CPU 上训，ResidualMLP 在 GPU 上训，都跑完再取平均，时间完全够——就是当时没想到，做完了才意识到。如果补上这步，预期能再提 0.5-1pp。

## 五、汇报应答

**被问到"为什么没选树模型"**：

> "我们选 MLP 是因为课程文档推荐了神经网络方向，而且 ResidualMLP 的每个组件都能溯源到参考文献，在方案汇报的创新性维度上能讲得更清楚。树模型这条路当然也走得通——很多同学选了，效果应该也不差。如果时间允许，集成树模型和神经网络是最优解。"

**被问到"为什么有的组两个都用了"**：

> "集成的方法很简单——两个模型各训各的，预测取平均。因为树模型和神经网络看数据的角度不同，误差模式不完全重叠，平均之后互相抵消。这是最有性价比的升级。"

**被问到"如何继续优化"**：

> "性价比最高的不是换更复杂的模型，而是用一个树模型如 LightGBM 做集成——改几行代码、多跑一次训练，预期能到 7-8%。"
