## 方案一：基础集成（投入 2 小时，预期 +0.5~1pp）

### 原理

树模型和神经网络看数据的方式不同，犯的错不重叠，预测值取平均后互相抵消。

### 步骤

**1. 写 LightGBM 模型类**

新建 `mdl_lgb.py`，参考现有 `mdl.py` 的风格。关键参数：

```python
params = {
    'objective': 'regression',
    'metric': 'rmse',
    'num_leaves': 127,
    'learning_rate': 0.05,
    'feature_fraction': 0.8,
    'bagging_fraction': 0.8,
    'bagging_freq': 5,
    'min_data_in_leaf': 100,
    'verbose': -1,
}
```

**2. 在 meow.py 里加集成逻辑**

```python
# 现有代码（保持不变）
engine.model.load("model_weights.pt", "scaler.pkl")
ydf_mlp = engine.model.predict(xdf)

# 新增：LightGBM 预测
from mdl_lgb import MeowModelLGB
lgb_model = MeowModelLGB()
lgb_model.load("lgb_model.txt")
ydf_lgb = lgb_model.predict(xdf)

# 简单平均
ydf["forecast"] = (ydf_mlp + ydf_lgb) / 2
```

**3. 在另一个同学的电脑上训 LightGBM**

LightGBM 纯 CPU，不需要 GPU，任何电脑都能训。6-11 月 700 万条数据预计 5-10 分钟。

## 方案二：集成 + 损失函数改进（投入半天，预期 +1~1.5pp）

在方案一的基础上，ResidualMLP 改用 Huber Loss：

```python
# 替换 mdl.py 中的 MSELoss
lossFn = nn.HuberLoss(delta=0.001)
```

Huber Loss 对小误差用 MSE（梯度连续），对大误差用 MAE（不受极端值绑架）。金融数据有厚尾，fret12 偶尔出现 ±5% 以上的极端波动，Huber Loss 不会被这些点带偏。

---

## 方案三：集成 + 损失函数 + 标签优化（投入一天，预期 +1.5~2pp）

在前两个方案基础上，标签不做原始的 fret12，改用波动率标准化：

```python
# feat.py 中新增
df["fret12_vol"] = df["fret12"] / (df["midpx_ret1_std24"] + 1e-8)
# 用 24 分钟波动率标准化后的收益率作为训练目标
```

同时增加一个分类辅助任务：涨跌方向预测。

```python
# 修改 ResidualMLP 头部
# 原来：head(64→1) 只输出回归值
# 改为：head_reg(64→1) + head_cls(64→1) 同时输出回归值 + sigmoid 分类
# 总 loss = 0.7 * Huber(reg_pred, y) + 0.3 * BCE(cls_pred, direction)
```

## 方案四：全面优化（投入两三天，预期冲 8-10%）

在方案三基础上再加：

| 优化项 | 做法 | 预期收益 |
|--------|------|---------|
| 特征筛选 | 用 LightGBM 的 feature_importance 去掉贡献最低的 10 个特征 | 更稳 |
| 滚动窗口扩展 | 加 36 min、60 min 窗口的 MA/STD | +0.3-0.5pp |
| 更多交互特征 | 用 feature_importance 指导，补 5-8 组高价值交互 | +0.3-0.5pp |
| 三模型集成 | LightGBM + ResidualMLP + XGBoost 取平均 | +0.2-0.3pp |
| 学习率 warmup | 前 5 个 epoch 从 lr/10 线性增长到 lr | 更稳 |
