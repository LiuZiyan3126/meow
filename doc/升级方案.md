# MEOW 项目升级方案

> 当前：ResidualMLP · 62 特征 · Pearson 0.0643 | 目标：逐级突破 7% → 8% → 10%

---

## 第一步：LightGBM 集成（+0.5~1pp，2 小时）

### 目标

Pearson 从 0.0643 提升到 **0.069 ~ 0.074**。

### 原理

树模型和神经网络看数据的方式不同——树模型做硬阈值切分，神经网络做光滑拟合。两者犯的错不重叠，预测值取平均后互相抵消。

### 操作

**1. 安装 LightGBM**

```powershell
pip install lightgbm
```

**2. 新建 `src/mdl_lgb.py`**

参考现有 `src/mdl.py` 的风格，实现 LightGBM 的训练和推理。注意沿用相同的特征标准化器（StandardScaler）和时序切分验证集逻辑。

关键参数：

```python
params = {
    'objective': 'regression',
    'metric': 'rmse',
    'num_leaves': 127,
    'learning_rate': 0.05,
    'feature_fraction': 0.8,
    'bagging_fraction': 0.8,
    'bagging_freq': 5,
    'min_data_in_leaf': 100,
    'verbose': -1,
}
```

训练后用 `booster_.save_model()` 保存为 `lgb_model.txt`。

**3. 修改 `meow.py` 入口**

```python
if __name__ == "__main__":
    engine = MeowEngine(h5dir="./archive", cacheDir=None)

    # 加载 ResidualMLP
    if os.path.exists("model_weights.pt") and os.path.exists("scaler.pkl"):
        engine.model.load("model_weights.pt", "scaler.pkl")
    else:
        engine.fit(20230601, 20231130)

    # 评估集数据
    dates = engine.calendar.range(20231201, 20231229)
    rawData = engine.dloader.loadDates(dates)
    xdf, ydf = engine.featGenerator.genFeatures(rawData)

    # ResidualMLP 预测
    ydf["forecast_mlp"] = engine.model.predict(xdf)

    # LightGBM 预测
    from src.mdl_lgb import MeowModelLGB
    lgb = MeowModelLGB()
    lgb.load("lgb_model.txt")
    ydf["forecast_lgb"] = lgb.predict(xdf)

    # 简单平均
    ydf["forecast"] = (ydf["forecast_mlp"] + ydf["forecast_lgb"]) / 2

    # 评估
    engine.evaluator.eval(ydf)
```

**4. 训练与验证**

在同学 RTX 4060 上训 LightGBM（纯 CPU，5-10 分钟），拿到 `lgb_model.txt` 拷回项目目录，运行 `python meow.py` 看 Pearson。

## 第二步：损失函数改进（+0.2~0.4pp，30 分钟）

### 目标

在第一步基础上，Pearson 提升到 **0.072 ~ 0.079**。

### 原理

MSE 对大误差的惩罚是平方级，金融数据有厚尾——fret12 偶尔出现极端波动（±5% 以上）。这些极端样本会绑架 MSE 的训练方向。Huber Loss 在小误差区间用 MSE（平滑），在大误差区间切换为 MAE（线性惩罚，不被绑架）。

### 操作

修改 `src/mdl.py` 中一行：

```python
# 原来
lossFn = nn.MSELoss()

# 改为
lossFn = nn.HuberLoss(delta=0.001)
```

delta 的取值：fret12 的标准差约 0.007，Huber 的 delta 取标准差的 10-20% 左右，这里用 0.001。

重新训练 ResidualMLP，新权重覆盖 `model_weights.pt`。

## 第三步：更多交互特征（+0.3~0.5pp，半天）

### 目标

在第二步基础上，Pearson 提升到 **0.075 ~ 0.084**。

### 原理

目前只有 4 个手动交互特征（imb×spread、obi×ret、act×spread、obi×vol）。可以用 LightGBM 的 feature importance 来找到"特征 A 和特征 B 各自贡献中高、但它们的交互还没被利用"的组合，针对性地补 5-8 组。

### 操作

**1. 分析 feature importance**

训完第一步的 LightGBM 后，导出特征重要性：

```python
importance = lgb_model.feature_importance(importance_type='gain')
# 按重要性排序，找 top-15 特征
```

**2. 构造候选交互**

从 top-15 特征中选 5-8 对构造交互特征，添加到 `src/feat.py` 的 G 类中。优先选"各自贡献高 + 相关性低"的组合。

**3. 重新训练两个模型，取平均**

## 第四步：标签优化 + 辅助任务（+0.3~0.5pp，一天）

### 目标

在第三步基础上，Pearson 提升到 **0.078 ~ 0.090**。

### 原理

**标签波动率标准化**：fret12 的大小受波动率影响——高波动时段的 fret12 天然更大，但不代表信号更强。用 `fret12 / std24` 做标准化后，不同波动率状态下的标签可比。

**涨跌分类辅助**：除了回归涨跌幅，同时预测涨跌方向。两个任务共享隐层表示，分类任务的梯度可以帮回归任务学到更好的特征表示。

### 操作

**1. 标签标准化**

在 `src/feat.py` 中新增一列：

```python
df["fret12_norm"] = df["fret12"] / (df["midpx_ret1_std24"] + 1e-8)
```

训练时用 `fret12_norm` 作为标签，推理时还原：

```python
pred_norm = model.predict(xdf)
pred = pred_norm * (xdf["midpx_ret1_std24"].values + 1e-8)
```

**2. 多任务学习**

修改 `src/nn_model.py` 中的 ResidualMLP：

```python
# 原来：head(64→1)
# 改为：
self.head_reg = nn.Linear(64, 1)   # 回归涨跌幅
self.head_cls = nn.Linear(64, 1)   # 分类涨跌方向
```

Loss 加权组合：

```python
loss = 0.7 * HuberLoss(reg_pred, y_norm) + 0.3 * BCEWithLogitsLoss(cls_pred, y_direction)
```

## 第五步：三模型集成 + 特征精选（冲 8-10%，两天）

### 操作

| 优化项 | 做法 | 预期收益 |
|--------|------|---------|
| XGBoost 加入集成 | LightGBM + ResidualMLP + XGBoost 三模型取平均 | +0.2~0.3pp |
| 特征精选 | 去掉 feature importance 最低的 10 个特征 | 更稳 |
| 长窗口特征 | 加 36min、60min 的 MA/STD | +0.2~0.3pp |
| 学习率 warmup | 前 5 epoch 从 lr/10 线性增长到 lr | 更稳 |
