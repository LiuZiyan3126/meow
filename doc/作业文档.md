一、背景介绍   

传统金融理论普遍认为市场中金融资产的价格遵循随机游走 (Random Walk) 假说，即其价格的变化是不可预测的 。然而也有许多研究交易的从业者认为股票价格的波动存在规律性，即根据历史数据我们可以一定程度上预测未来的价格变动 。这两者不同的观点逐渐演变为两个不同的流派，即“Q 宗” (Q-quant) 和“P 宗” (P-quant) 。Q-quant 主要通过利用风险中性测度和无套利原则来对金融资产进行定价，并追求完美对冲各种风险 。他们主要服务于投资银行，也就是我们经常听到的金融市场中的“卖方” 。P-quant 预测金融资产未来的价格变化，并利用量化交易的经典风险因子模型实现统计套利，他们是金融市场中的“买方”，常见于各种私募公司或自营交易部门 。  

事实上，由于金融数据普遍易于获取，数据分析技术早在上世纪 70 年代就在金融行业中开始流行 。早期的理论普遍采用统计学中的经典线性回归模型 (及其变种)，该模型认为股票价格的变动受到很多不同因子的影响，且总回报率 (return) 等于不同因子的回报率乘以权重之后的线性加和 。该方法至今仍然占据主流地位，因为线性模型具有良好的“可解释性”，而可解释性对于交易策略的复盘和分析具有重要作用，且线性多因子模型在不断的发展和更新中变得非常的成熟和模块化 。近年来，部分从业者开始使用机器学习中的非线性模型替代传统的统计学模型，并取得了很好的效果 。与传统的线性模型相比，梯度决策树、神经网络等模型可以更好的学习到数据中的非线性关系，目前业界已经越来越多得采用以神经网络为代表的非线性模型 。  

二、项目介绍   

和其他机器学习任务 (比如视觉，推荐，NLP) 不同的是，股票价格预测往往不追求过高的准确率 。这是因为首先金融数据中充满了各种不同的随机噪声 (或者可以理解为无法预测的因子)；其次股票价格时间序列往往是 non-stationary，及其波动率会随着时间变化 。然后股票价格回报率的分布一般不满足高斯分布，而属于某种长尾分布 。这些统计特征使得我们在预测股价回报率的时候不会有特别高的准确率 。一般来说，我们预测的准确率和我们预测的时间长度成反比，也就是说预测时间的越短，准确率越高 。在本项目中，我们提供大约 300 只股票从 2023 年 6 月 1 日至 2023 年 12 月 31 七个月的分钟级数据，预测的长度 (forecast horizon) 为 12 分钟，即预测 12 分钟后的价格变化率 ：  



$$fret12=\frac{P_{12}-P_{0}}{P_{0}}$$

  

其中，$P_{0}$ 是股票当下的价格，$P_{12}$ 为 12 分钟以后的股票价格 。  

项目整体自由度较高，和常见的预测类任务相同，我们一般把流程分为数据分析，特征挖掘，模型定义，结果评价等几个常见环节 。由于任务量比较大，我们推荐大家组队进行，但是希望组内每个成员都可以参与到整个项目的所有环节，而不是只负责某个特定的环节 。

1. 预测评价   

我们使用三个不同的指标来综合评价最终预测结果的好坏 (权重各占三分之一) 。我们会给出所有 Team 的预测结果排名，其中排名靠前的 team 可以获得这部分的满分 。  

- 

  **Mean Squared Error (MSE)**   

  $$\frac{1}{N}\sum_{i=1}^{N}(y_{i}^{\prime}-y_{i})^{2}$$

    

- 

  **Pearson Correlation**   

  $$\frac{\sum_{i=1}^{N}((y_{i}^{\prime}-\overline{y})(y_{i}-\overline{y}))}{\sqrt{\sum_{i=1}^{N}(y_{i}^{\prime}-\overline{y}^{\prime})^{2}}\sqrt{\sum_{i=1}^{N}(y_{i}-\overline{y})^{2}}}$$

    

- 

  **R Squared**   

  $$1-\frac{MSE(model)}{MSE(baseline)}=1-\frac{\sum_{i=1}^{N}(y_{i}-y_{i}^{\prime})^{2}}{\sum_{i=1}^{N}(\overline{y_{i}}-y_{i}^{\prime})^{2}}$$

    

其中，$y_{i}^{\prime}$ 是预测值，$y_{i}$ 是每个观测值 $i$ 的真实值 。  

- 

  **TIPS 1**：一般来说这三个指标中，MSE 比较低的话，其他两个指标也会不错 。当然同学们在选取 loss function 时可以使用但不局限于 MSE 。不同的 loss function 会使模型表现出不同的效果 。  

- 

  **TIPS 2**：从业人员经常使用 Pearson Correlation (或其变种) 作为对比指标 。这里可以给大家一个参考：项目原始代码使用 6 个简单特征和 Ridge 线性回归模型得到的预测结果的 correlation 仅仅为 2%-3% 。业内一些顶级的团队的预测结果的 correlation 可以到 20%-30% 甚至以上 (当然他们使用的数据种类可能更为丰富) 。我们对大家的能做到的预期为 5%-10% 。如果能超过 10% 则会有比较多的加分 。

1. 什么是 Order Book   

一个 OrderBook 是一个包含了所有交易者订单信息的集合 。想买的 order 叫做 bid order, 想卖的 order 叫做 ask order, 这些 bid 和 ask 的 order 一旦满足了各自的条件就会完成配对，产生一笔交易 。我们假设所有的订单都有一个限价，即买单有一个不高于的价格，卖单有一个不低于的价格 。OrderBook 上面 bid 和 ask 有很多不同的价位，每个价位记录了该价位包含订单的总数量，例如下图是某股票某时刻的 orderbook 5 档之内的一个快照 (snapshot) ：

2. 市场事件 (Add, Trade, Cxl)   

举例说明，每天股票市场开盘之后，连续竞价阶段，当投资者想要买入某个股票时，他会确定买入的限价和数量，并将这个交易指令发给证券交易所 。此时一个新的订单事件 (Add event) 就产生了 。如果 OrderBook 上面有合适的对手盘 (即有人也想在这个价位或者更低的价位卖出)，两个订单就会撮合并产生成交，此时一个新的成交事件就产生了 (Trade event) 。如果没有合适的对手盘，或者订单没有成交完，这个订单或者其剩余部分就会留在 OrderBook 上面，找到对应的价位排好序，等待对手盘的出现 。如果在这个订单完全成交完之前，投资者想要取消订单，就会发送一个取消指令给交易所，这个时候就会产生一个撤单事件 (Cancel event, 也写作 Cxl event) 。  

3. 主买主卖   

Add event 可以细分为 add buy event 和 add sell event，分别对应买和卖 。同理 Cxl event 也可以分为 cxl buy event 和 cxl sell event 。但是对于一个成交事件 (trade event) 来讲，其中必然有一个买单和一个卖单，我们如何理解数据中的“trade buy”和“trade sell”的概念 ？举例说明，当一个卖单找不到对手盘而停留在 OrderBook 上等待时，假如这个时候出现了一个新的条件合适的买单并和该卖单成交，我们就称这个交易事件为 trade buy event，这是因为在这两个一买一卖的订单中，买单主动“击中”了卖单，显得更为主动 。如果上面例子反过来就是 trade sell event 。  

4. 市场微观结构   

市场微观结构 (market microstructure) 是指资产交易价格形成与发现的过程与运作机制 。市场微观结构和股票短期价格波动之间有着千丝万缕的联系 。充分理解并研究市场微观结构有助于我们从本质上理解短期价格波动的原因，并找到其中的规律，总结出优秀的特征 。  

5. 动量和反转   

动量效应 (Momentum effect) 一般又称惯性效应，是指股票的收益率有延续原来的运动方向的趋势，即过去一段时间收益率较高的股票在未来获得的收益率仍会高于过去收益率较低的股票 。反转效应 (Reversal effect)是指在一段较长的时间内，表现差的股票在其后的一段时间内有强烈的趋势经历相当大的逆转，要回复到正常水平 (reversal to mean)，而在给定的一段时间内，最佳股票则倾向于在其后的时间内出现差的表现 。  

一般我们用来模型预测的特征都可以归类于动量类或者反转类，或在不同条件下表现不同 。但令人惋惜的是，传统涨跌幅因子的反转效应并非一直稳定 。动量与反转的本质是股价对信息的反应程度 。实证发现股票成交量大、大单占比高的涨跌幅统计学上表现为反转，而成交量小、小单占比高的统计学上表现为动量 。动量与反转，只是涨跌幅因子呈现于表面的一种现象，其背后的本质，其实是不同的投资者交易行为，导致股票价格对市场信息的反应程度不同，即究竟是反应不足，还是反应过度 。若反应不足，则股票当前的价格走势在未来仍有一定的延续性，涨跌幅因子表现为动量；若反应过度，则涨跌幅因子应当表现为反转 。而成交量的大小也好，大小单的交易占比也罢，都只不过是衡量、或者干脆说是推测股价反应程度的线索 。
